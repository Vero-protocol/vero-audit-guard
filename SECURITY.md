# Security Policy

## Supported Versions

This repository's `main` branch is actively maintained. Security fixes are applied to supported components and releases maintained by the Vero Protocol team.

For vulnerability reports, please include the affected component and version or commit hash so the security team can assess the affected scope.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

For the complete vulnerability reporting process, including the reporting contact, required information, response timelines, scope, and safe-harbor provisions, see:

[Vulnerability Disclosure Policy](VULNERABILITY_DISCLOSURE.md)

Thank you for helping keep Vero Protocol and its users secure.
