# Verifiable Audit Trail

`verifiable-audit-trail` handles the cryptographic hashing of audit reports generated by `scanner-engine` and anchors those hashes onto the Stellar/Soroban ledger to ensure an immutable, tamper-evident audit history for the Vero Protocol.

---

## CLI Usage & Operational Modes

The module provides a Command Line Interface (CLI) supporting two primary execution modes:

* **`anchor`**: Computes the SHA-256 hash of a local audit report JSON and submits a transaction to the Stellar network with the digest attached in the transaction `memo`.
* **`verify`**: Queries prior audit anchors from the Stellar network via the Horizon API, extracts the on-chain memo identifiers, and compares them against local report hashes to detect tampering or missing anchors.

---

## Memo Computation & Horizon Verification Flow

1. **Local Identifier Computation:** Computes a SHA-256 digest of the target report and formats it to match Stellar's 32-byte `MEMO_HASH` constraint.
2. **Horizon Lookup:** Queries the Stellar Horizon REST API (`/transactions/{tx_hash}`) to retrieve transaction metadata.
3. **Integrity Comparison:** Compares the local report digest against the retrieved on-chain memo hash.
4. **Incident Handling:** On hash mismatch or missing anchors, logs an integrity incident and exits with a failure status code.

## Environment Variables

| Variable | Description | Default |
| --- | --- | --- |
| `HORIZON_URL` | Horizon server endpoint used for Stellar audit anchoring and lookup | `https://horizon-testnet.stellar.org` |
| `STELLAR_NETWORK` | Target Stellar network (`testnet` or `mainnet`) | `testnet` |
| `AUDIT_KEYPAIR_SECRET` | Stellar secret key used to sign anchor transactions. Leave empty for dry-run hash computation. | *(empty)* |

## Development & Execution

* **Build package** (Compiles TypeScript with `tsc` into `dist/`):
  ```bash
  npm run build
  ```

* **Run tests** (Executes Jest unit test suite):
  ```bash
  npm test
  ```

* **Run entry point** (Executes compiled script `node dist/index.js`):
  ```bash
  npm start
  ```
